# 독립 에이전트 리뷰 루프

## 적용 대상

코드, 아키텍처, 보안, 데이터 계약, 라이브·배포 동작 변경은 독립 리뷰가
필수다. 오탈자처럼 동작에 영향을 주지 않는 문서 변경은 생략할 수 있으며,
생략 사실을 인계에 적는다.

## 역할

- 구현자: 범위를 확인하고 수정·검증한 뒤 diff와 위험을 전달한다.
- 리뷰어: 구현자와 다른 에이전트다. 첫 검토에서는 코드를 수정하지 않고
  정확성, 회귀, 보안, 데이터 손실, 테스트 누락을 찾는다.
- 구현자는 발견사항을 해결하고 같은 리뷰어에게 재검토를 요청한다.

## 반복 절차

1. 구현자가 목표, 변경 파일, 제외 범위, 위험, 실행한 검증을 리뷰 패킷으로
   전달한다.
2. 리뷰어는 실제 diff와 가까운 코드를 읽고 발견사항을 P0~P3로 기록한다.
3. 발견사항에는 파일, 가능한 한 좁은 줄, 재현 근거와 수정 기대값을 넣는다.
4. 구현자가 P0~P2를 수정하고 관련 검증을 다시 실행한다.
5. 같은 리뷰어가 수정 diff를 재검토한다.
6. 최대 3회 안에 `APPROVE`되지 않으면 자동 반복을 멈추고 사용자에게
   남은 쟁점과 선택지를 보고한다.

P0는 데이터 손실·보안·중대한 잘못된 거래, P1은 일반적인 정확성·회귀,
P2는 제한적인 결함·테스트 누락, P3는 비차단 개선사항이다.

## 기록과 게이트

리뷰 증거는 커밋하지 않는 `.agent-reviews/<task-id>.json`에 기록한다.
템플릿과 최종 검사는 다음과 같다.

```powershell
python .\tools\review_gate.py --print-template
python .\tools\review_gate.py .\.agent-reviews\<task-id>.json
```

게이트는 구현자와 리뷰어가 다른지, 같은 리뷰어가 재검토했는지, 3회 제한,
P0~P2 해소, 최종 `APPROVE`, 필수 구조 테스트 통과와 실패 검증 부재를
확인한다. 실행하지 않은 검증은 `not_run`과 사유를 함께 기록한다.

필수 기본 검증:

```powershell
python -m unittest test_architecture.py -v
```

실제 변경에 가까운 문법 검사·집중 테스트도 리뷰 기록에 추가한다. 전체
백테스트, 대량 다운로드, Telegram 발송·봇 실행은 별도 실행 승인을 요구한다.
